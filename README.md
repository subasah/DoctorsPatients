# Heidi Health Landing Page

A modern, responsive landing page for a healthcare AI assistant platform. This page features a clean, professional design optimized for healthcare professionals.

## Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations and transitions
- **Interactive Elements**: 
  - Mobile-friendly navigation menu
  - FAQ accordion
  - Smooth scrolling navigation
  - Button ripple effects
  - Scroll-based animations
- **Complete Sections**:
  - Hero section with call-to-action
  - Features showcase
  - How it works steps
  - Customer testimonials
  - Pricing plans
  - FAQ section
  - Footer with links

## How to Use

Simply open `index.html` in your web browser to view the landing page.

### Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. No build process or dependencies required!

### File Structure

```
/workspace/
├── index.html      # Main HTML structure
├── styles.css      # All styling and responsive design
├── script.js       # Interactive functionality
└── README.md       # This file
```

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with flexbox, grid, and animations
- **Vanilla JavaScript**: No frameworks required
- **Google Fonts**: Inter font family

## Customization

### Colors

The color scheme is defined in CSS variables at the top of `styles.css`:

```css
:root {
    --primary: #6366F1;
    --primary-dark: #4F46E5;
    --primary-light: #818CF8;
    --secondary: #F3F4F6;
    --text-primary: #111827;
    --text-secondary: #6B7280;
    /* ... more colors */
}
```
